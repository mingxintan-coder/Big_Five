# 五象人格测试

基于大五人格（Big Five）研究的 25 型人格测试，在线使用：https://mingxintan-coder.github.io/Big_Five/

- 五个维度：动↔静、新↔常、律↔随、和↔锋、稳↔敏，每维 3 个细项，共 15 个细项
- 25 种角色、6 大族群，按原型距离匹配
- 完整版 60 题 / 快速版 30 题
- 结果包括：总览、细项、职业兴趣（RIASEC 近似推算）、合作与关系、个人规划、逐题回答
- 保存记录：每次测试自动保存在本机浏览器，可查看、命名、删除
- 恋爱配对：从记录、分享链接或角色类型选择对象，给出配对指数和分析
- MBTI 换算与星座组合分析（星座部分仅供娱乐）
- 分享链接把作答编码在网址 # 后面，不经过服务器，打开即可看到完整结果

单文件网页，无需构建。仅供自我了解，不是临床诊断，也不适合用于招聘筛选。
